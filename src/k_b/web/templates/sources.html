Sources et conditions d’utilisation

Sources

  • Papiers: l’API (interface de programmation) d’arXiv; ses métadonnées sont sous CC0 1.0. Conditions d’utilisation de l’API d’arXiv (en anglais, site externe, nouvel onglet).
  • Failles: le catalogue KEV (Known Exploited Vulnerabilities) de la CISA (Cybersecurity and Infrastructure Security Agency), sous CC0 1.0.
  • Alertes: la GitHub Advisory Database, sous licence CC BY 4.0 (site externe, nouvel onglet).
  • Releases: les dépôts GitHub suivis; chaque note de version reste sous la licence de son dépôt.
  • Articles de newsletters: tldr.tech, lu sur le web; les textes restent à leur éditeur.

Les papiers viennent de l’API d’arXiv, qui demande cette mention à chacun de ses utilisateurs:

Thank you to arXiv for use of its open access interoperability.
